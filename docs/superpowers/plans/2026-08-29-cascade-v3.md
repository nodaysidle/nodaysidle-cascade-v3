# NODAYSIDLE Cascade V3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to execute this plan inline. Steps use checkbox syntax for tracking. Do not dispatch subagents, commit, push, create branches, or alter Git configuration.

**Goal:** Build, test, package, sign, install, launch, and locally prove a new exact-five deterministic compiler at `/Applications/NODAYSIDLE Cascade V3.app`.

**Architecture:** One Zod semantic schema feeds a pure TypeScript preset compiler and five renderers. A narrow Rust boundary owns DeepSeek HTTPS/cancellation and verified atomic export; a DOM controller owns only UI state and the immutable preview packet.

**Tech Stack:** Tauri 2, Rust 2021, TypeScript 5.9, Vite 7, Vitest, Zod, native DOM/CSS, reqwest.

**Spec:** `docs/superpowers/specs/2026-08-29-cascade-v3-design.md`

## Global Constraints

- Product name: `NODAYSIDLE Cascade V3`.
- Bundle ID: `com.nodaysidle.cascade.v3`.
- Output is exactly `PRD.md`, `ARD.md`, `TRD.md`, `TASKS.md`, and `AGENTS.md`.
- DeepSeek models are exactly `deepseek-v4-pro` and `deepseek-v4-flash`, with no automatic fallback.
- Provider output contains semantic meaning only; every mechanical relationship is local.
- API keys remain memory-only and never enter logs, files, preferences, URLs, errors, or Markdown.
- No React, database, analytics, telemetry, account system, remote backend, or older-compiler compatibility.
- Protected paths in `docs/evidence/protected-baseline.md` remain byte-identical.
